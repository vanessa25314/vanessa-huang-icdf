# Vanessa Huang｜國合會職缺申請網站

## 開啟方式
解壓縮後，以 Chrome、Edge、Safari 或 Firefox 開啟 index.html，即可瀏覽並操作網站，不需安裝套件或啟動伺服器。

## 內容與互動
- 中英文切換
- 五項職務需求與個人經歷對應
- 三組可展開案例
- 工作方法、學經歷及聯絡資訊
- 自適應版面、鍵盤分頁操作及減少動畫偏好支援

## 修改方式
所有 HTML、CSS 與 JavaScript 均位於 index.html。
固定文案的中文與英文分別位於 data-zh 與 data-en 屬性。
職務對應、案例及工作方法位於頁面下方 data 物件的 zh / en 區段。
修改經歷或日期時，請同步調整兩種語言。

## 備註
此為個人求職作品頁，並非國合會或歐銀官方網站。
網站未部署或公開發布。沒有分析追蹤、後端服務或外部字型依賴。
Email 與 LinkedIn 連結需使用相應郵件程式或網路服務；其他內容與互動可離線使用。
